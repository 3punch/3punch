## 🧠 About

I like problems that have a clean mathematical core hiding inside them. Most of my
projects begin with a question like *"what actually happens under the hood here?"* —
and end up as a tool, a library, or a full application.

- 🔢 **Algorithms & complexity** — building tools that reason *symbolically* about
  algorithms rather than just timing them
- 🐍 **Backend engineering** — Django applications, databases, and API design
- 🤖 **Applied ML & AI** — machine-learning fundamentals and practical LLM/bot tooling
- ⚙️ **Systems & security** — peer-to-peer networking, cryptography, database design

## 🚀 Projects

| Project | What it is | Stack |
| :-- | :-- | :-- |
| **[`algocomp`](https://github.com/3punch/algocomp)** | A theoretical complexity-comparison framework. Give it two algorithms and it reports who wins asymptotically, by how much, from which input size the advantage matters, and the trade-offs — all from declared Big-O profiles, with no benchmark noise. Ships with a large catalogue spanning DP, number theory, crypto, linear algebra, ML, optimisation, and geometry. | `Python` |
| **[`django-marketplace`](https://github.com/3punch/django-marketplace)** | A full e-commerce platform built from scratch: custom Trie-based search, persistent cart, coupon validation, and order management. | `Django` · `HTML` |
